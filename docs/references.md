# references.md — External Evidence Sources

Companion to the [benchmark ledger](benchmarks.md): **internal** claims about fasterRag are backed by ledger entries; **external** claims (literature, vendor documentation) are backed by the sources below. Every externally-sourced statement in this repository should trace to a row here; a sourced claim that can't is a bug ([todo.md](todo.md)). When our own measurements disagree with a source, the ledger wins and the affected defaults are re-examined.

## Rules for adding sources

1. A new external claim in any doc adds (or reuses) a row here in the same change.
2. Quote numbers exactly as the source states them; if a source is singular or preliminary (like R3), say so wherever it is cited.
3. Vendor behavior rows (R4–R10) are re-verified when the pinned vendor version changes; stale rows are updated, not silently trusted.
